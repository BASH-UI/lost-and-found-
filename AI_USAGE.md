# AI Usage Report

## 1. AI Tools Used

**ChatGPT**

I used ChatGPT as a learning and development assistant while building the Campus Lost & Found application.

It helped me understand web development concepts, plan features, troubleshoot errors, improve code, and prepare project documentation.

## 2. Important Prompts

Some of the important prompts I used during development included:

- "Help me build a Campus Lost & Found web application."
- "How do I connect my HTML, CSS, and JavaScript files?"
- "Help me understand how to use Git and GitHub for my project."
- "How do I deploy my application using Vercel?"
- "Help me set up Supabase and understand how to connect it to my application."

These prompts helped me understand concepts, explore implementation methods, and troubleshoot problems during development.

## 3. Features or Code Generated with AI

ChatGPT assisted with:

- Suggestions for the application structure and features.
- HTML structure and CSS styling guidance.
- JavaScript implementation suggestions.
- CRUD functionality guidance.
- Search and filtering logic.
- Browser localStorage implementation.
- Supabase database setup and SQL schema suggestions.
- GitHub and Vercel deployment troubleshooting.
- README and AI usage documentation drafts.

## 4. Changes I Made to AI-Generated Code

I reviewed, tested, and modified suggested code during development.

Some of the changes included:

- Adjusting HTML elements and CSS styling to fit the application.
- Changing CSS sizing values when elements did not display correctly.
- Connecting the HTML, CSS, and JavaScript files.
- Modifying JavaScript functionality while implementing the application.
- Updating Git and Vercel configuration to resolve deployment issues.
- Working through Supabase configuration and database setup.

I made development decisions based on the needs of the project and tested changes to understand how they affected the application.

## 5. Errors and How I Resolved Them

I encountered several challenges during development:

- **CSS layout issues:** Some elements did not display as expected. I investigated the CSS properties and adjusted sizing values.
- **File linking issues:** I checked file paths and script configuration to ensure the HTML, CSS, and JavaScript files were connected correctly.
- **Vercel deployment issues:** I needed to add a build script to `package.json` and configure `.gitignore` to prevent `node_modules` from being tracked.
- **Git issues:** I learned how to identify untracked files and use Git commands to stage, commit, and push changes.
- **Supabase integration issues:** I encountered difficulties connecting the database and authentication to the application. I investigated the configuration, but the complete integration was not finished.

## 6. How I Tested and Verified AI-Generated Code

I tested the application by:

- Running the application locally using Vite.
- Creating lost-item and found-item posts.
- Checking that posts appeared in the application.
- Testing the search and filtering functionality.
- Editing existing posts.
- Changing item statuses.
- Deleting posts.
- Refreshing the browser to check localStorage persistence.
- Deploying the application to Vercel and opening the live website.
- Checking the application on different screen sizes.

The Supabase integration was not fully verified as a working part of the submitted application.

## 7. What I Learned

Using AI as a development assistant helped me learn:

- How HTML, CSS, and JavaScript work together.
- How JavaScript handles user interactions.
- How CRUD operations work in web applications.
- How browser localStorage stores application data.
- How Git and GitHub help manage source code.
- How Vercel is used to deploy web applications.
- The purpose of databases, authentication, and environment variables.
- How to investigate errors and test code.

Most importantly, I learned that AI-generated code should not simply be copied without understanding it. It needs to be reviewed, modified, and tested. AI can assist development, but the developer is responsible for understanding and verifying the final application.
